DASHBOARD NXE360 INSPIRED BY XBOX360
<hr>
HOW TO INSTALL?
<hr>
Download the theme zip and extract it in the themes folder of your Batocera, then put the script NXE360 - Installation.sh in the ports roms folder and start the script. After 2 min, the theme is ready.
<hr>
REQUIREMENTS: 1 GB VRAM in EmulationStation
<hr>
Press Start to open the main menu.
Go to System Settings, then Developer.
Set the VRAM Limit to the maximum (1000 MB).
Go back using the Back button; the setting will be saved.
<hr>
HOW TO CHANGE MY AVATAR?
<hr>
Launch 360sona in Ports and create your avatar, then press Select + Start to export and wait a few minutes.
You can change your avatar in your theme configuration.
