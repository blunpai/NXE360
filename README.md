# DASHBOARD NXE360
### Inspired by the Xbox 360 NXE dashboard

---

## HOW TO INSTALL?

1. Download the theme zip and extract it into the `themes` folder of your Batocera (`\\BATOCERA\share\themes\`).
2. Rename the folder `NXE360-main` to `NXE360`.
3. Copy `NXE360 - Installation.sh` from the theme folder to the Ports folder (`\\BATOCERA\share\roms\ports\`).
4. *Main Menu → Game Settings → Update Gamelists*.
5. Launch **NXE360 - Installation** from **Ports**.

That's all!

---

## REQUIREMENTS: 1 GB VRAM

1. Press **Start** to open the Main Menu.
2. Go to **System Settings**, then **Developer**.
3. Set the **VRAM Limit** to the maximum (1000 MB).
4. Go back using the **Back** button; the setting will be saved.
