HOW TO INSTALL?
<hr>
Download the theme zip and extract it in the themes folder of your Batocera, then put the script NXE360 - Installation.sh in the ports roms folder ans start the script after 2min, thé thème is ready
<hr>
REQUIREMENTS: 1 GB VRAM
<hr>
Press Start to open the main menu.
Go to System Settings, then Developer.
Set the VRAM Limit to the maximum (1000 MB).
Go back using the Back button; the setting will be saved.
